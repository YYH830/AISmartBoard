# 猫猫桌宠 · 动作提示词合集

> 用途：把「猫猫桌宠」各动作的绿幕动画一集做出来。
> 配套脚本：`gen_action_frames.mjs`（生成首尾帧）、`check_cat_video.py`（视频体检）、`check_action_frames.py`（首帧体检）

---

## 一、工作流程

```
① 用图片模型生成各动作的「绿幕首尾帧」   →  refs/actions/<动作>-first.png / -last.png
② 用视频模型（图生视频）把首尾帧变成动作视频  →  inbox/<动作>.mp4
③ 视频体检（绿幕是否纯、有没有裁切、是否原地）  →  python check_cat_video.py inbox/<动作>.mp4
④ 丢进 cat-media/inbox/ 交给处理管线抠图 + 找无缝循环 + 出透明动图
```

**首尾帧怎么填**：第 ① 步产出的每个动作都有 `-first.png` 和 `-last.png` 两个文件，视频工具里的**首帧填 `-first`、尾帧填 `-last`**。

> 注意：六个动作的 `-first` 与 `-last` 目前**内容完全相同**（同一张图的副本）。
> 原因是它们都是**循环动作**（待机、瞌睡、睡觉、洗脸、跳跃都要反复播放），首尾同姿势才能天然闭环。
> 如果你想要的是「只演一遍」的单次动作，就不该首尾同图，告诉我另做。

**核心前提**：**不要**再用那张通用的站立图当所有动作的首帧了 —— 模型会被那张图带跑，
比如「睡觉」只能从站姿一路演变成蜷缩，动作又长又假，还容易被裁切。

## 六、参数建议

| 项 | 建议值 | 说明 |
|---|---|---|
| 生成方式 | **图生视频** | 首帧填 `-first.png`，尾帧填 `-last.png` |

## 七、避坑要点

1. **绿幕颜色不用较真色号**。处理管线会**自动识别实际背景色**再抠图，模型把绿调偏一点、偏暗一点都能用。
   实测各动作背景的「绿优势」在 79 ~ 113 之间，全部合格，不必为了颜色反复重生成。

2. **务必确认猫没被裁切**。这是最容易翻车的一项 —— 之前那版 `standing.mp4` 就有 74/145 帧贴着左边缘，
   主体被切断，抠图后会出现平直的断口。
   生成后先跑：`python check_cat_video.py inbox/你的视频.mp4`，它会报出贴边帧数，并出一张带
   **红色安全边距参考框**的抽帧拼图（主体越框即为裁切）。

3. **待机类动作要「原地不动」**。走路动作的位移量实测在画幅 4~5% 左右，待机类应明显更小。
   体检脚本会给出主体中心漂移量，超过 6% 会提示。

4. **先校验再交付**。两个体检脚本的用法：

```powershell
cd "cat-media"
chcp 65001                                    # 避免中文输出乱码
python check_cat_video.py inbox/xxx.mp4       # 视频体检：绿幕 / 裁切 / 位移
python check_action_frames.py                 # 首帧体检：绿幕 / 裁切 / 位置
```

**各动作的「姿势」段落**（即上表 `【动作姿势】` 处的内容）：

| 动作 | 姿势描述 |
|---|---|
| `idle` | 不用生成，直接复用参考图 |
| `doze` | 标准的猫坐姿：后腿弯曲坐着，前爪并拢撑在身前，身体竖起，眼睛闭成弯弯的弧线，脑袋微微向下低垂，尾巴松弛地绕在身前地面上。 |
| `sleep` | 侧躺蜷缩成一团睡觉的姿势：身体缩成圆润的一团趴在地面上，四条腿收在身体下方只露出爪尖，尾巴从身后绕过来包住身体，脑袋枕在前爪上，眼睛完全闭上，神态安详。 |
| `stretch` | 伸懒腰的最高点姿势：两条前爪向前伸出平贴在地面上，前胸贴近地面，背部高高弓起，后腿伸直、屁股向上翘起，尾巴向上翘起，眼睛闭着。 |
| `groom` | 坐着的洗脸姿势：猫安静地坐在自己屁股上，两只后腿都弯曲收在身下、两只后爪连同小腿一起平贴在地面上承重，后腿不抬起也不向两侧张开撑地；两只前爪中只有一只抬起举到脸侧，另一只前爪稳稳撑在地面上；始终有且仅有一只爪子离地，其余三只爪子全部贴在地面上；脑袋微微侧过去靠近抬起的爪子，舌头露出一小截，尾巴悠闲地摊在身后地面上。 |
| `hop` | 四只爪子全部踩在地面上、身体压低蹲伏的蓄力姿势：四条腿都弯曲、肚子贴近地面，背部略微拱成圆弧，尾巴平贴地面向后伸直，两只耳朵向前竖起，眼睛睁大发亮盯着前方，整体呈「准备向上起跳」的压缩姿态。 |
