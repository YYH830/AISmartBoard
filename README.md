# AI智能看板（AISmartBoard）

> 一个**自托管**的轻量任务看板：数据就是 Markdown 文件，日历拖拽排期，内置 AI 智能分析。个人用、拉上团队一起用都合适。

- 🗂 **数据在手** —— 一个台账 = 一个 `.md` 文件，纯文本、人眼可读、可手工编辑、可版本管理、可随时备份带走
- 🧩 **零依赖** —— 服务端只用 Node.js 内置模块，不用 `npm install`，没有数据库
- 📅 **日历排期** —— 把任务拖到月历上，按「预估人天」自动占天数；支持工作日 / 自然日、法定节假日与周末标注
- 🤖 **AI 智能分析** —— 直接读你的台账再总结 / 分析，流式输出；可接自己的大模型（内置 DeepSeek 预设 + 自定义 OpenAI 兼容）
- 👥 **个人 / 团队** —— 个人台账私密独立；团队看板可加成员协作，含负责人标识、操作历史、冲突自动合并
- 🎨 **深色 / 浅色**主题

---

## 界面

左侧是**月历**，右侧是**任务池 / AI 智能分析**两个标签页：把任务写进任务池，再拖到日历上，就完成了排期。顶部有日历设置、筛选、导出、账号入口等。

## 功能特性

### 任务
- 字段：编号、任务、状态（未完成 / 已完成 / 已暂停）、**优先级**（高 / 中 / 低）、**标签**（多个）、预估人天、备注；团队看板多一列「负责人」
- 任务池：搜索（`/` 聚焦）、按状态排序、**筛选**（按 状态 / 优先级 / 标签）
- 拖动卡片调整顺序

### 日历
- 月视图，任务按「预估人天」占位，跨天自动连成一条（连续条 + 泳道）
- **排期方式**：自然日 / 工作日（自动跳过周末与法定节假日）
- 2026 全年法定节假日 + 调休 + 周末标注
- **日历设置**：自定义任务条上展示的字段（任务名 / 优先级 / 标签 / 人天）
- 底栏统计：本月已排天数、涉及任务数、工作日负荷

### AI 智能分析
- 顶部「任务池 / AI 智能分析」双标签；AI 直接读当前台账 MD 后作答（SSE 流式）
- 支持接你自己的模型（内置 DeepSeek：`DeepSeek-V4.1-Flash` / `DeepSeek-V4-Pro-0813`；或选「自定义（OpenAI 兼容）」填 Base URL / 模型名 / API Key）
- 配置**按登录账号分别保存**，各账号各自的 Key、互不可见
- 历史记录可查看 / 单条删除 / 清空（删除均二次确认）

### 团队协同
- 团队看板 + 全局成员池（一个账号可加入多个团队）
- 服务端权限校验、负责人标识、操作历史（谁改了什么）
- 乐观并发控制 + 任务行级三方合并，多人同时编辑不互相覆盖

### 数据
- 数据即 Markdown：任务池表 + 排期表（见下方「数据格式」）
- 多台账：工作一个、生活一个、项目再开一个，侧边栏随时切换
- 删除台账会移入 `.trash`（可找回）；「导出」按钮可下载当前台账 `.md` 原文

## 快速开始

### 方式一：部署到服务器（随时随地浏览器访问）
```bash
bash start.sh start      # 启动（后台运行）
bash start.sh status     # 查看状态
bash start.sh logs       # 实时日志
bash start.sh restart    # 重启
bash start.sh pass       # 查看 / 重设访问账号密码
```
首次运行会自动生成 `.env`（默认账号 `admin` / 密码 `12345`，**开放到公网前请务必改成 12 位以上强密码**）。公网部署建议配 Nginx 反代 + HTTPS，详见 [`DEPLOY.txt`](./DEPLOY.txt)。

### 方式二：Docker
```bash
# 先把 docker-compose.yml 里的 WTK_PASS 改成自己的密码
docker compose up -d          # 启动
docker compose logs -f        # 看日志
docker compose down           # 停止
```

### 方式三：本机使用
- Windows：双击 `launchers/open-board.vbs`
- macOS：双击 `launchers/open-board.command`
- 或命令行：`node app/server.js`（默认 http://127.0.0.1:8765 ，可加 `--port=9000`）

## 数据格式（Markdown）

所有内容都存成 Markdown 表格，可直接用记事本编辑：

任务池：

| 编号 | 任务 | 状态 | 优先级 | 标签 | 预估人天 | 备注 |
| :--- | :--- | :--- | :--- | :--- | ---: | :--- |

排期：

| 编号 | 开始 | 结束 |
| :--- | :--- | :--- |

- 团队看板的「任务池」表会多一列 **负责人**
- 列名支持中英文别名（如 `优先级/priority`、`标签/tags`），列顺序可自行调整
- 保存后看板会自动刷新；也可在外部编辑文件，界面轮询到变化自动重载

## 环境变量

| 变量 | 说明 | 默认 |
| :--- | :--- | :--- |
| `WTK_HOST` | 监听地址（服务器部署用 `0.0.0.0`） | `127.0.0.1` |
| `WTK_PORT` | 监听端口（被占用时自动顺延） | `8765` |
| `WTK_USER` | 主账号 | `admin` |
| `WTK_PASS` | 主账号密码（服务器部署必填） | — |
| `TZ` | 时区 | — |

- **额外账号**：项目根目录 `.users.json`，格式 `[{"user":"张三","pass":"密码"}]`，新增后需重启服务
- **AI 配置**：项目根目录 `.ai-config.json`，按账号保存各自的 provider / baseUrl / model / apiKey

> ⚠️ `.env`、`.users.json`、`.ai-config.json`、`data/` 已全部加入 `.gitignore`，**不会上传到仓库**。示例见 [`.env.example`](./.env.example)。

## 常见问题

- **端口被占用？** 会自动往后顺延（最多试 40 个）。
- **删错了？** 台账删除移入 `.trash`；任务删除有「撤销」；删除类操作普遍带二次确认。
- **想连别的模型？** AI 设置里选「自定义（OpenAI 兼容）」，填 Base URL / 模型名 / API Key 即可（如 Kimi：`https://api.moonshot.cn/v1` + `kimi-k3`）。
- **公网访问要注意什么？** 一定要改掉默认密码，并建议上 HTTPS（见 `DEPLOY.txt`）。
