  AI智能看板 · 使用说明
════════════════════════════════════════════════════════════════════════

（本文件是纯文本，用记事本直接打开即可。用任何支持 UTF-8 的编辑器查看，中文都不会乱码。）

一个以 Markdown 文件为台账的个人AI智能看板。

左边是月历，右边是任务池：把任务写进任务池，再拖到日历上，就完成了排期。
所有数据都以 Markdown 表格存在文件里，随时能用记事本打开、也能手工编辑。

  · 两种用法：可以在自己电脑上用，也可以放服务器上随时访问
               服务器部署请看同目录的《DEPLOY.txt》
  · 数据在手：一个台账就是一个 .md 文件，内容人眼可读，工具坏了数据也在
  · 多台账：工作一个文件、生活一个文件、重要项目再开一个，侧边栏随时切换
  · 零依赖：服务端只用 Node.js 内置模块，不用 npm install，也没有数据库

  1. 快速开始
════════════════════════════════════════════════════════════════════════

这个看板有两种用法，先选一种：

  ┌─ 用法一：部署到服务器（随时随地用浏览器访问）───────────────────┐
  │  把整个文件夹传到服务器，执行  bash start.sh start ，            │
  │  然后浏览器访问  http://<服务器IP>:8765/  ，输入密码即可。       │
  │  完整步骤见同目录的《DEPLOY.txt》。                    │
  └─────────────────────────────────────────────────────────────────┘

  ┌─ 用法二：在自己电脑上用（不联网，只监听本机）───────────────────┐
  │  就是下面 1.1 ~ 1.5 讲的内容。                                   │
  └─────────────────────────────────────────────────────────────────┘


1.1 前置条件：安装 Node.js
────────────────────────────────────────

只需要装一次。

  (1) 打开 https://nodejs.org ，下载 LTS 版本
  (2) 一路「下一步」装完即可（约 30 MB，不需要任何额外配置）
  (3) 想确认是否装好：打开命令行 / 终端，输入  node -v
      能显示版本号（例如 v20.18.0）就成功了

  Windows 用户：即使没装 Node.js 也能用 —— 双击「launchers\open-board.vbs」时会自动
  改用系统自带的 PowerShell 服务（功能一样，只是打开界面用的是普通浏览器
  标签页，且暂不支持多台账）。

  macOS 用户：如果已装 Homebrew，也可以直接执行  brew install node


1.1.1 关于登录（本机用法可以跳过）
────────────────────────────────────────

项目根目录有个 .env 文件，里面是【服务器部署】的配置（监听地址、端口、登录账号密码）。
默认内容是：

      WTK_HOST=0.0.0.0
      WTK_USER=admin
      WTK_PASS=12345

本机双击「launchers\open-board.vbs」或「launchers/open-board.command」时，启动脚本会
强制把监听地址拉回 127.0.0.1，所以看板绝不会暴露到局域网 —— 但 .env 里的账号密码仍然
生效，也就是说本机双击也会先看到登录页（用 admin / 12345 登录即可）。

  · 想在本机模拟服务器的登录效果：直接双击启动脚本就行。
  · 想在本机彻底关掉登录（回到双击即用的老样子）：把 .env 文件删掉或改名即可。
  · 想连服务器时一起改动，就编辑 .env，改完重启服务。

  ⚠ admin / 12345 是方便你立刻上手的初始值，太简单。一旦对外开放访问（服务器部署），
    请务必改成 12 位以上的复杂密码，详见《DEPLOY.txt》第 6 章。


1.2 Windows 启动
────────────────────────────────────────

双击「launchers\open-board.vbs」即可。

它会做两件事：在后台静默启动本地服务（不会闪出黑色命令行窗口），然后打开
一个独立的界面窗口（没有地址栏和标签页，用起来就像一个本地软件）。

想更顺手的话：

  · 右键「launchers\open-board.vbs」→「发送到」→「桌面快捷方式」，
    再把快捷方式拖动到任务栏固定
  · 需要看日志排查问题时，改双击「launchers\debug-console.bat」
    （会保留一个命令行窗口显示运行信息）

  提示：「launchers」文件夹里那三个文件，平时都不用管，只有启动出问题
        时才需要碰 debug-console.bat。日常只认 open-board 这一个，「app」
        文件夹也不用打开，你的台账数据都在「data」文件夹里。


1.3 macOS 启动
────────────────────────────────────────

第一次使用，先赋予执行权限：在「终端」里进入本文件夹，执行一次

      chmod +x "launchers/open-board.command"

之后就可以双击「launchers/open-board.command」启动了。不想改权限的话，也可以每次
都这样启动：

      bash "launchers/open-board.command"

  如果 macOS 提示「无法打开，因为来自身份不明的开发者」，请右键文件 →
  打开 → 在弹窗里再点一次「打开」，之后就不再询问。

  原因：OneDrive / 网盘不同步 macOS 的"可执行"权限标记，换一台 Mac 后可能
        需要重新执行一次 chmod +x。


1.4 关闭
────────────────────────────────────────

点界面右上角那个带绿点的「服务运行中」徽标，面板里选「停止服务」，确认即可。

  · 也可以直接关掉那个命令行窗口（Mac 上执行  pkill -f server.js ）
  · 停止后徽标会变红显示「服务已停止」，本页面无法再读写台账

界面窗口关掉后，后台服务可能还在运行。这没关系：下次双击「launchers\open-board.vbs」
时，它会检测到服务已存在并直接打开界面，不会重复启动、也不会占用多个端口。

1.5 服务状态面板
────────────────────────────────────────

点顶栏右上角的「服务运行中」徽标（绿点），会打开一个服务管理面板，可以看到：

  · 服务地址与进程号（PID）
  · 服务已经运行了多久
  · 台账目录的完整路径、当前正在用的台账
  · 运行环境（Node 版本、操作系统）
  · 监听地址（是否对外开放）与访问保护是否开启（含登录账号）

面板里的动作：

  重启服务
      服务先停止再自动启动，约 1～3 秒后页面会自动刷新。适用于界面卡住、
      或改过程序文件后需要重新加载的情况。已保存的内容不会丢失。

  停止服务
      彻底关闭后台服务（相当于收工）。会先弹确认，未保存的改动也会被拦住。

  退出登录
      只在启用了登录保护时出现。点了就退出登录、清除登录状态，回到登录页。

关于「为什么没有『启动服务』按钮」：这个页面本身就是后台服务发出来的，能看到
页面就说明服务一定在运行，所以不存在"需要启动"的状态。

  本机用法下要启动服务，双击「launchers/open-board.vbs」（Windows）
  或「launchers/open-board.command」（Mac）—— 建议发到桌面或固定到任务栏。

  服务器部署下要启动服务，在服务器上执行  bash start.sh start 。

  3. 基本操作
════════════════════════════════════════════════════════════════════════

3.1 新建任务
────────────────────────────────────────

三种方式，任选：

  (1) 点顶栏「＋ 新建任务」
  (2) 按键盘 N
  (3) 点日历中某一天的右上角「＋」（会顺便把任务排到这一天）

新建后会弹出「任务详情」窗口，填好内容点「保存」。


3.2 任务详情窗口
────────────────────────────────────────

  任务内容
      要做什么，一句话说清

  状态
      未完成 / 已完成 / 已暂停，点一下即切换

  预估人天
      预估需要多少人天，支持小数（如 0.5）。下面有常用值快捷按钮

  排期
      可以设置多段不连续的日期，例如「这周一两天，下周一一天」。
      点「添加排期」增加一段，点该行右侧的 × 删除这一段

  备注
      补充说明、依赖、交付物等

保存方式：点「保存」按钮，或按 Ctrl + Enter。


3.3 标记状态
────────────────────────────────────────

两种方式：

  · 在任务池卡片上：直接点那行状态标签（如「未完成」），每点一次按
    未完成 → 已完成 → 已暂停 循环切换
  · 在任务详情窗口里：点状态按钮选择

状态会同时反映在任务池卡片和日历上的横条上（横条颜色不同，已完成的还会加
删除线）。


3.4 拖到日历上排期
────────────────────────────────────────

从任务池拖动卡片，放到日历的某一天，就为这个任务创建了一段排期。放下的位置
会实时高亮提示。

拖动时：

  · 把卡片拖到任务池里 ＝ 取消排期，回到未排期状态
  · 拖到顶部的 ‹ / › 按钮上停留约 0.6 秒，会自动翻到上 / 下个月
  · 拖到窗口边缘，日历或任务池会自动滚动

如果某一天的格子变红并显示细线，就是在提示"松手后会插到这里"。


3.5 调整已有排期
────────────────────────────────────────

在日历上直接操作任务横条：

  拖横条的中间
      整段排期前后平移，天数不变

  拖横条的左边缘
      改这段的开始日期

  拖横条的右边缘
      改这段的结束日期

  拖到任务池
      取消这段排期

跨天任务在日历上会显示成一条连续的横条，跨越它占用的每一天。


3.6 调整顺序与筛选
────────────────────────────────────────

  · 任务池内排序：按住卡片左侧的 ⠿ 手柄上下拖动即可
  · 按状态排序：点「按状态排序」，会按 未完成 → 已暂停 → 已完成 重排
  · 筛选：点「全部 / 未完成 / 已暂停 / 已完成 / 已排期 / 未排期」这些按钮
  · 搜索：在搜索框输入关键字，或按 / 直接聚焦搜索框


3.7 删除任务与撤销
────────────────────────────────────────

  · 删除：鼠标移到任务池卡片上，点右上角出现的 ×；
          或在任务详情窗口里点「删除任务」
  · 撤销：按 Ctrl + Z（macOS 为 Cmd + Z），可撤销最近的操作


3.8 切换月份
────────────────────────────────────────

  · 点日历标题两侧的 ‹ / ›
  · 按键盘 ← / →
  · 按 T 或点「今天」，快速回到当前月

  4. 多个台账（工作 / 生活 / 项目）
════════════════════════════════════════════════════════════════════════

一个台账 = 一个 .md 文件。你可以工作一个、生活一个、重要项目再开一个，互不
干扰。


4.1 打开侧边栏
────────────────────────────────────────

点顶栏最左侧的 📁 图标。侧边栏默认是收起的，需要时才展开。

点侧边栏以外的任何地方会自动收起（按 Esc 也可以），所以不会挡住日历。


4.2 侧边栏能做什么
────────────────────────────────────────

  切换台账
      点列表里的台账名

  新建台账
      点右上角 ＋，输入名字（如「生活」），系统自动补 .md 后缀并立即切换过去

  重命名
      鼠标移到台账上，点 ✎ 图标（只改文件名，内容不变）

  删除
      鼠标移到台账上，点 🗑 图标（会有确认提示）

  打开台账文件夹
      点底部「打开台账文件夹」，在文件管理器里定位到这些 .md 文件

列表里每个台账都会显示任务数量和最近修改时间，当前正在用的那一个会高亮。


4.3 关于删除
────────────────────────────────────────

出于安全考虑，删除台账不会真正删掉文件，而是把它移动到「data」文件夹下的
.trash 子文件夹里（文件名前面加上时间戳）。

如果误删了，进入「data\.trash」把对应文件改名后移回「data」文件夹即可找回。
（Windows 上 .trash 是隐藏文件夹，需要在文件资源管理器里勾选「显示隐藏的项目」。）

另外，工具不允许删除最后一个台账 —— 至少要保留一个。


4.4 切换台账时会怎样
────────────────────────────────────────

  · 切换前，当前台账里未保存的改动会先自动保存，不会丢
  · 界面会记住你上次用的是哪个台账，下次打开自动回到它

  5. 数据文件说明
════════════════════════════════════════════════════════════════════════

5.1 存在哪里
────────────────────────────────────────

所有台账 .md 文件都统一存放在「data」文件夹里（不在根目录，避免和程序文件混在
一起）。默认有一个「tasks.md」。

点界面侧边栏底部的「打开台账文件夹」按钮，可以直接在文件管理器里定位到这个
文件夹。想手工备份或拷贝台账，复制这个文件夹就够了。


5.2 目录结构
────────────────────────────────────────

整个工具就长这样（服务器部署另有说明，见《DEPLOY.txt》）：

  data\                     你的数据，台账 .md 全在这里
  app\                      程序文件，平时不用进去
  launchers\                Windows / Mac 本机启动用的脚本
  README.txt                本文件
  DEPLOY.txt                服务器部署步骤
  start.sh                  Linux 服务器的启动脚本

「app」文件夹里放的是 index.html、server.js、login.html 这些程序本身，升级或
排错时才需要打开，日常使用完全不用管它。


5.3 文件长什么样
────────────────────────────────────────

      # AI智能看板

      > 本文件由「AI智能看板」自动读写，可手工编辑；保存后看板会自动刷新。
      > 最后更新：2026-10-13 09:45

      ## 一、任务池

      | 编号 | 任务   | 状态   | 预估人天 | 备注             |
      | :--- | :----- | :----- | -------: | :--------------- |
      | T1   | 写周报 | 未完成 |      0.5 | 周五前给组长     |

      ## 二、排期

      | 编号 | 开始       | 结束       |
      | :--- | :--------- | :--------- |
      | T1   | 2026-10-12 | 2026-10-13 |

  · 「任务池」表格是任务清单，编号（T1、T2…）是任务的身份标识
  · 「排期」表格说明哪几个任务占用哪几天，一个任务可以有多行（多段排期）


5.4 可以手工编辑吗？
────────────────────────────────────────

可以。用任何编辑器（记事本、VS Code、Typora 都行）打开修改并保存，界面会在
2 秒内自动同步过来，并弹一个「已同步外部修改」的提示。

注意几点：

  · 改完记得保存文件，界面靠文件的修改时间来感知变化
  · 排期表里引用的编号，必须在任务池表里存在，否则会被忽略
  · 日期请写成  2026-10-13  这种格式
  · 单元格里不要出现竖线字符 | （会破坏表格）


5.5 数据安全提醒
────────────────────────────────────────

  · 工具只操作「data」文件夹里的 .md 文件，不会动别的文件
  · 如果你把整个文件夹放在 OneDrive / 坚果云 / iCloud 等同步盘里，
    多台电脑可以共用同一份数据
  · 但请避免两台电脑同时打开并编辑同一个台账，否则网盘会生成"冲突副本"。
    建议一次只在一台机器上使用

  7. 常见问题
════════════════════════════════════════════════════════════════════════

双击启动脚本后什么都没发生？
────────────────────────────────────────

  (1) 看是否已经有界面窗口被打开了（有时会开在已有浏览器窗口的新标签页里）
  (2) 检查 Node.js 是否装好：命令行执行  node -v
  (3) 改双击「launchers\debug-console.bat」（Windows），
      它会保留命令行窗口，能看到具体报错信息


提示端口被占用 / 界面打不开？
────────────────────────────────────────

服务默认用 8765 端口，如果被别的程序占用，它会自动往后试 8766、8767…
界面上显示的地址就是实际地址。

如果界面里提示"当前不是通过本地服务打开的"，说明你可能是直接双击
index.html 打开的。这种方式浏览器不允许读写本地文件，请改用启动脚本。


任务改动没保存到文件里？
────────────────────────────────────────

看顶栏的保存状态：

  · 已保存 09:30     ＝ 已写入文件
  · 保存中…          ＝ 正在写，稍等一下

想把数据搬到另一台电脑？
────────────────────────────────────────

把整个文件夹复制过去就行（台账 .md 在「data」文件夹，程序文件在「app」文件夹）。

  · Windows 直接双击「launchers\open-board.vbs」
  · Mac 第一次需要先  chmod +x "launchers/open-board.command"


想换回浅色 / 深色主题？
────────────────────────────────────────

点顶栏的 🌓 图标切换，选择会记住。


我的数据会被上传吗？
────────────────────────────────────────

不会。本机用法下，服务只监听本机地址（127.0.0.1），外部设备访问不到，也不连接
任何互联网服务。

服务器部署下，数据存在你自己的服务器上，不会传给任何第三方；但服务会对外开放，
所以务必把默认的 admin / 12345 改成自己的账号密码（详见《DEPLOY.txt》）。


服务器部署后的问题（打不开 / 忘记密码 / 安不安全）？
────────────────────────────────────────

都在《DEPLOY.txt》里：第 5 章讲配域名和 HTTPS，第 6 章讲安全注意事项，
第 7 章是打不开、忘记密码这类问题的排查步骤。
